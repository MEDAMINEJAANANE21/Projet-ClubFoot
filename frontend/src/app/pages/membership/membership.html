Rejoindre le Wydad

Porter le maillot du Wydad est un honneur, le mouiller est un devoir. Remplissez le formulaire pour devenir membre du club

Comment ça marche

  • Remplissez le formulaire ci-contre.
  • Préparez les pièces demandées : acte de naissance, photo d'identité, CIN.
  • Le club étudie votre demande et vous recontacte.

Bon à savoir

Ce site est un projet étudiant : votre demande est enregistrée dans la base de démonstration, rien de plus.
